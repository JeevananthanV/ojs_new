## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/JeevananthanV/ojs_new.git
cd ojs_new
```

### Run Locally

Open `index.html` in any web browser, or serve using any static web server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js npx
npx serve .
```

Navigate to `http://localhost:8080`.
